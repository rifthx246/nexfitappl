# NEXFIT website

A responsive, static first-version website for NEXFIT. It includes:
- Home dashboard
- Workout plan selector
- Exercise library
- Local progress counter
- Responsive mobile and desktop layout

## Preview locally
Open `index.html` in a browser.

## Deploy with GitHub and Vercel (phone-friendly)
1. Sign in to GitHub with help from a parent/guardian where needed.
2. Create a **public or private** repository named `nexfit`.
3. In the repository, choose **Add file → Upload files**.
4. Upload `index.html`, `styles.css`, `script.js`, and `favicon.svg` (you can also upload this README).
5. Commit the files.
6. Sign in to Vercel and choose **Add New → Project**.
7. Import the `nexfit` GitHub repository.
8. Keep the framework preset as **Other** (or no framework), leave build command and output directory blank, then choose **Deploy**.
9. Vercel will provide a `.vercel.app` address.

## Important limitations
This is a static front-end prototype. The progress count is stored only in the current browser on the current device. It does not yet have member accounts, cloud sync, a database, admin tools, or app-store builds. Do not collect sensitive personal information in this version. Have a qualified adult review privacy, safety, accessibility, and legal requirements before public launch.

The custom domain `nexfitapp.com` must be separately registered and then added in Vercel if available.
